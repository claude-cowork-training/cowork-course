# Playbook: Weekly Client Status Digest
**Trigger:** Friday 15:00 · **Owner:** Priya Nair
**Inputs:** week's meeting notes + pipeline.csv in weekly-inputs/
**Output:** client-digest-YYYY-MM-DD.md — one section per active client: status (green/yellow/red), one-line why, next action + owner
**Standards:** three clients, never more than 5 lines each · red status requires a named recovery action · ends with "needs a decision" list (may be empty)
