# Metamorfeus glossary (terms Claude should know)
- **QBR** — quarterly business review (client-facing, deck + one-pager)
- **Digest** — the weekly Ferrostar alert-triage summary (Monday, one page)
- **Pilot** — fixed-fee first engagement; success criteria written before kickoff
- **The board numbers** — revenue, utilization %, pipeline value (always those three, that order)
- **De-identified extract** — Cascadia data with all PHI removed before it reaches us; the only form we ever touch
