# Capstone Checklist (used in lesson 2.5)
- [ ] Picked ONE real recurring task (weekly or monthly, not one-off)
- [ ] Wrote the 4-line brief (goal / inputs / output / constraints)
- [ ] Built the context files the task depends on
- [ ] Ran it end to end at least twice
- [ ] Documented it with the workflow-brief template
- [ ] Passed the colleague test (someone else could run it from the doc alone)
- [ ] Time-saved estimate written down — labeled as an estimate
